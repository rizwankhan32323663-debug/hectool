Developer Tools — 18 free online tools

Eighteen utilities for the small jobs inside every dev day: testing regex, decoding JWTs, diffing text, minifying CSS and JavaScript, converting timestamps, and generating QR codes, barcodes, meta tags and robots.txt files. Each tool is single-purpose and instant — paste, click, copy, and get back to real work.

  • QR Code Generator — Create a scannable QR code for text or a URL and download it as PNG.
  • Text Diff Checker — Compare two texts line by line and highlight additions and removals.
  • Regex Tester — Test a regular expression against text and list every match.
  • HTML Entity Encoder / Decoder — Encode special characters to HTML entities or decode entities back.
  • CSS Minifier — Shrink CSS by removing comments and extra whitespace.
  • JS Minifier (Basic) — Basic JavaScript minifier — strips comments and extra whitespace.
  • JWT Decoder — Decode a JWT header and payload — signature is never verified.
  • Unix Timestamp Converter — Convert Unix timestamps to dates and dates back to timestamps.
  • Binary / Hex Text Translator — Convert text to binary or hex and back again.
  • Roman Numeral Converter — Convert between Roman numerals and regular numbers (1-3999).
  • Barcode Generator — Generate Code 128, EAN, UPC and Code 39 barcodes from any text or number and download as PNG or SVG.
  • JSON to CSV Converter — Convert JSON arrays into CSV you can open in Excel or Google Sheets, with proper quoting.
  • CSV to JSON Converter — Convert CSV data into clean, pretty-printed JSON with the header row as keys.
  • Markdown Editor — Write Markdown with a live preview, then download the Markdown or the rendered HTML.
  • HTML to Markdown Converter — Convert HTML code into clean Markdown for docs, READMEs and notes.
  • CSS Box Shadow Generator — Design box shadows visually with sliders and copy the ready CSS code.
  • Meta Tag Generator — Build SEO and social meta tags for any page and copy the ready-to-paste code.
  • Robots.txt Generator — Create a robots.txt file with allow and disallow rules and a sitemap line.
