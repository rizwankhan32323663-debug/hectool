Passport Photo Resizer

What is this tool?

The Passport Photo Resizer resizes a photo to a passport or exam size and compresses it toward a file-size target of 20, 30 or 50 KB. Output is a JPG you can download.

It adjusts JPEG quality to get as close as possible to the target without going over it. If the target still cannot be reached, it shrinks the dimensions in steps and reports the honest final size, dimensions and whether the target was met.

How to use Passport Photo Resizer

  1. Upload a JPG, PNG or WebP photo, up to 20 MB.
  2. Choose a photo size in the Photo size field.
  3. Choose a target file size in the Target file size field, or No limit.
  4. Tap Resize and compress.
  5. Check the output dimensions, actual file size and whether the target was met, then tap Download JPG.

Is it free?

Yes. The Passport Photo Resizer is free on HecTool — no account, no sign-up, no payment.

Limitations

  • Input is limited to JPG, PNG or WebP files up to 20 MB, and output is always JPG.
  • A size target is a goal, not a guarantee; if it cannot be reached, the honest final size is reported.
  • It does not check official photo rules for background, face position or framing; check the requirements yourself.

Alternatives

  • Canva (canva.com) — offers photo resizing tools.
  • iLoveIMG (iloveimg.com) — offers image resizing and compression tools.

Example (illustrative)

Input: a 2000 x 1500 px photo, Passport size, 30 KB target. Output (illustrative): a 413 x 531 px JPG reported at, for example, 28 KB, with the target shown as met.

Frequently asked questions

Which photo sizes are offered?

Passport 35 x 45 mm (413 x 531 px at 300 dpi), US 2 x 2 in (600 x 600 px), and Exam small (200 x 250 px).

What happens if my photo cannot reach the target size?

The tool reduces the dimensions in 10% steps and retries, then reports the honest final size and that the target was not met.

What file types can I upload?

JPG, PNG or WebP, up to 20 MB. The downloaded output is always a JPG.

Will the result meet official passport photo rules?

Not necessarily. The tool only resizes and compresses; check the official rules for background, framing and other requirements yourself.

Is my photo uploaded anywhere?

No. The tool runs in your browser, nothing is uploaded, and your photo stays on your device.
