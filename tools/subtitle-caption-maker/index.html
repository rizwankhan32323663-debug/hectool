Subtitle Caption Maker

What is this tool?

The Subtitle Caption Maker builds SRT and VTT caption files from lines you type, each with a start time and an end time. Add as many rows as you need, generate the captions, and preview, copy or download the result in either format.

It does not transcribe audio. You type the words and the times yourself, in mm:ss, mm:ss.mmm or seconds form. Rows are checked so the end time comes after the start time, and overlapping rows produce a warning naming the rows involved.

How to use Subtitle Caption Maker

  1. Add a row for each caption line, using Add row for more rows and Remove to delete a row.
  2. Enter the start time and end time for each line in mm:ss or mm:ss.mmm format, or in seconds.
  3. Type the caption text for each line.
  4. Tap Generate captions and check the preview and any overlap warning.
  5. Choose SRT or VTT in the format field to switch the preview, then use Download .srt, Download .vtt or Copy captions.

Is it free?

Yes. The Subtitle Caption Maker is free on HecTool — no account, no sign-up, no payment.

Limitations

  • Manual timing only; it does not transcribe audio or video, and no audio or video file can be uploaded.
  • Each row needs a valid start time, a valid end time and caption text, and the end time must be after the start time.
  • Overlapping captions only produce a warning; the times must be fixed by hand before the file is used.

Alternatives

  • Kapwing (kapwing.com) — offers subtitle and caption tools.
  • Desktop subtitle editors — desktop programs for editing subtitle files offer manual caption timing and SRT and VTT export.

Example (illustrative)

Input: one row with start 00:00.000, end 00:03.500 and text Hello and welcome. Output (illustrative): an SRT cue numbered 1 with 00:00:00,000 to 00:00:03,500 followed by the text Hello and welcome, and the matching VTT cue in the VTT download.

Frequently asked questions

Does it transcribe audio or video automatically?

No. This tool does not transcribe audio. You type the words and the start and end times yourself, and it builds the caption file from what you enter.

What is the difference between SRT and VTT?

SRT and VTT are two caption file formats. SRT uses commas in timestamps and is widely supported by video players and editors. VTT uses dots in timestamps and starts with a WEBVTT header. The tool can generate both from the same rows.

Which time formats are accepted?

Times in mm:ss, mm:ss.mmm or hh:mm:ss.mmm form, or plain seconds such as 12.5. The end time of each row must be after its start time.

What happens if two captions overlap?

The tool still generates the file but shows a warning naming the overlapping rows, so you can fix the times before using the file.

Is anything uploaded anywhere?

No. The tool runs in your browser, nothing is uploaded, and the captions you type stay on your device.
