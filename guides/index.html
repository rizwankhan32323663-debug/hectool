HecTool Guides

These guides walk through common jobs step by step, using HecTool's own free tools. Each one tells you which tool to open, what to do in what order, and what to check before you finish — so you get the result right the first time, without signing up or installing anything.

Compress a photo to an exact file size

Upload forms and portals often reject photos over a set size. This guide shows how to pick the right format, lower quality in small steps, and resize only when you must, so the photo stays sharp while the file shrinks to fit. Your photo never leaves your device, because the image tools run in your browser. Read the photo compression guide, starting with the Image Compressor.

Merge PDFs free in your browser

Combining several PDFs into one file makes applications and reports easier to send and read. This guide covers adding files in the right order, checking page counts, and fixing a file with the splitter, organiser and rotator before you merge, so the final document comes out clean. Read the PDF merging guide, starting with the PDF Merger.

Build a free resume online

A clean resume gets read. This guide walks through filling in the Resume Builder, writing bullets with real evidence, tightening the wording, and saving the finished resume as a PDF — with honest notes on what to check yourself, since the builder does not spellcheck and AI suggestions must always be verified. Read the resume guide, starting with the Resume Builder.

How to use these guides

Open the guide for your task, follow the steps in order, and check the result at each checkpoint before moving on. The tips at the end of each guide cover the mistakes people make most often. If a step mentions a tool you have not used before, the link takes you straight to it, and every tool page includes its own answers to common questions. New guides are added for the jobs people ask about most — if a task you need is missing, suggest it through the contact page.
