How to Create a QR Code Free

A QR code turns a printed page, a poster or a business card into a tap-free link: anyone points a phone camera at it and lands on your page. HecTool’s QR Code Generator makes a scannable code for a link or a piece of text and downloads it as a PNG image. The code is generated in your browser, and nothing you type is stored.

Step 1: Decide what the code should contain

For a link, use the full address including https://, for example https://hectool.netlify.app. For text, keep it short: a Wi-Fi password, a short message or a phone number works well, while long paragraphs make a dense code that is harder to scan. Shorter content makes a simpler, more reliable code.

Step 2: Open the generator and enter your link or text

Open the QR Code Generator and paste your link or type your text. Check every character before you go further: one wrong letter sends scanners to the wrong page, and a printed code cannot be edited afterwards. Open the link in your browser first to confirm it loads.

Step 3: Download the PNG

Download the generated code as a PNG. Keep the downloaded file at its original size for printing, and make a smaller copy only for screen use. Do not screenshot the code from the page: a screenshot is lower quality and can blur the small squares that scanners read.

Step 4: Test the code before you share or print it

Open the PNG on your screen and scan it with your phone camera from a normal reading distance. It should open the right link or show the right text at once. If you plan to print it, test it on more than one phone if you can, and test a printed draft at the real size before ordering a full print run.

Step 5: Place it where people can scan it

Print the code at least 2 by 2 centimetres for a short link, and larger for longer links. Keep a clean white border around it, print it on a flat matte surface where possible, and put it where people can stand still at a comfortable distance — not behind glass that reflects light, and not so high or low that scanning is awkward.

Tips for codes that scan first time

Never cover part of the code with a logo or text: scanners need the whole pattern. Avoid very long links, because they make the pattern dense and slow to read. And if the destination page ever moves, the code will still point to the old address, so double-check the link again whenever you reprint.

Frequently asked questions

Do QR codes expire?

The code itself does not expire. But if the web page it points to is moved or deleted, the code will lead nowhere, so check the link whenever you reprint.

Will it work on iPhone and Android?

Yes. Modern iPhone and Android cameras read QR codes directly in the camera app, with no extra app needed.

Is my link stored anywhere?

No. The code is generated in your browser, and the link or text you enter is not uploaded or stored.
