Image Tools — 12 free online tools

Resize a photo for a form, shrink a heavy screenshot, convert PNG to JPG, crop, rotate or add a watermark — twelve image tools that handle the jobs people do daily. Because everything runs on your own device, your pictures are never uploaded to a server, and even big files finish in moments.

  • Image Resizer — Resize JPG, PNG or WebP images with optional aspect-ratio locking.
  • Image Compressor — Reduce image file size in your browser and control output quality.
  • Image Format Converter — Convert an image to JPG, PNG or WebP without uploading it.
  • Image Cropper — Crop an image with numeric margins and preview the result.
  • Image Rotator & Flipper — Rotate 90° or flip any image horizontally or vertically.
  • Image Filters — Apply grayscale, sepia, invert or blur to any image in your browser.
  • Image to Base64 — Convert any image to a Base64 data URL you can copy.
  • Base64 to Image — Turn a Base64 string back into an image — preview and download.
  • Meme Text Adder — Add bold top and bottom text to any image, meme-style.
  • Favicon Generator — Turn any image into favicon PNGs at 16×16, 32×32 and 48×48.
  • Image Color Palette — Extract the dominant colors from any image.
  • Image Watermark Adder — Add a text or logo watermark to any image with control over position, size and opacity.
