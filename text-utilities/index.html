Text Utilities — 21 free online tools

Twenty-one small tools that fix text fast: counting words and characters, switching case, removing duplicate lines, sorting lists, reversing strings, formatting JSON and generating slugs, passwords and hashes. Writers, students and developers use them to clean drafts and data before publishing — and because every tool runs locally, your text never leaves your device.

  • Word Counter — Count words, characters, sentences, paragraphs and reading time instantly.
  • Case Converter — Transform text into uppercase, lowercase, title, sentence, camel or snake case.
  • Detailed Character Counter — Full text stats: characters, words, sentences, paragraphs and reading time.
  • Remove Duplicate Lines — Drop repeated lines and keep only the first occurrence of each.
  • Sort Lines — Sort lines A-Z or Z-A, with optional case-insensitive sort.
  • Reverse Text — Reverse whole text, each line, or each word.
  • Text to Speech — Hear any text read aloud in your browser with adjustable speed and pitch.
  • Lorem Ipsum Generator — Generate placeholder paragraphs, sentences or words for mockups.
  • Password Generator — Strong random passwords with length, symbols and numbers options.
  • Random Number Generator — Random numbers in any range — one or many, with no repeats option.
  • UUID Generator — Generate one or many RFC-4122 v4 UUIDs.
  • Base64 Encoder / Decoder — Encode text to Base64 or decode Base64 back to text.
  • URL Encoder / Decoder — Encode text for URLs or decode percent-encoded URLs.
  • JSON Formatter & Validator — Format, validate and minify JSON with clear error messages.
  • Hash Generator — SHA-256, SHA-384 and SHA-512 hashes of any text, computed locally.
  • Morse Code Translator — Encode text to Morse code or decode Morse back to text.
  • Speech to Text — Turn your voice into text with your microphone — dictation in English, Urdu, Hindi and more languages.
  • Password Strength Checker — Check how strong a password is and how long it would take to crack — nothing leaves your browser.
  • Text Encryptor / Decryptor — Encrypt text with a password using AES, or decrypt it back — all locally in your browser.
  • Online Notepad — A simple notepad that saves as you type in your browser, with word count and download.
  • URL Slug Generator — Turn any title into a clean, SEO-friendly URL slug.

No. Open any tool and start using it right away.
